Frequently Asked Questions

Find answers to common questions about LCP, INP, CLS, testing and performance optimization.

Core Web Vitals are user-experience metrics focused on loading performance, interaction responsiveness and visual stability. The current metrics are LCP, INP and CLS.

LCP measures how quickly the main visible content loads, INP evaluates interaction responsiveness and CLS measures unexpected visual movement during the page experience.

Lab tests run under controlled simulated conditions. Field data reflects real users, devices, networks and interactions over time, so the two data sources can show different results.
